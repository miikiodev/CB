# Coffee Bean

Coffee Bean is a modern C++ framework for developing 2D games. It aims to provide a simple, flexible and maintainable foundation for game development.

## Technical objectives

- Support Windows and Linux.
- Provide a straightforward C++ API.
- Establish a modular and maintainable architecture.
- Provide common systems required for 2D game development.
- Favor simplicity, correctness and usability.
- Optimize performance where justified by measurements.

## Project scope

Coffee Bean aims to provide foundational systems for:

- Application and window management.
- Rendering.
- Input handling.
- Scene management.
- Resource management.
- Entity management.
- Physics.
- Audio and animation.

## Non-goals

- Visual game editor.
- 3D rendering.
- Visual scripting.
- Competing with commercial game engines.
- Implementing every subsystem from scratch.

These limitations may be reconsidered as the project matures.
